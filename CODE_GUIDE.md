# Как устроен код Midline

Шпаргалка к защите: что делает каждый скрипт и как они связаны между собой.

## Главная идея
Все участники боя (игрок, боты, миньоны, нейтралы, башни, Ancient) имеют два общих компонента:
- **Team**: команда (Blue / Red / Neutral) и тип (Minion, Hero, Tower, Ancient, Neutral). Метод `IsEnemyOf` решает, кто кого атакует.
- **Health**: здоровье, броня, щит (`invulnerable`), событие смерти `OnDeath` и урона `OnDamaged`. `LastAttacker` запоминает, кто ударил последним: на этом построен ластхит.

Остальные скрипты подписываются на события `Health` и читают `Team`, поэтому почти не зависят друг от друга.

## Цепочка систем (как в концепте)
Линии → ресурс → предметы → сила героя → контроль карты → объекты → путь к базе.

1. `WaveSpawner` выпускает миньонов каждые 25 с. Миньоны управляются `UnitAI`.
2. Игрок стреляет (`PlayerShooting`). Когда миньон умирает, `Bounty` смотрит `LastAttacker`: если это игрок, начисляет кредиты (ластхит).
3. Кредиты тратятся в `ShopPanel` (открывается через `ShopTerminal`). Предметы меняют поля `PlayerShooting`, `Health`, `PlayerAbilities`.
4. `Tower` стреляет по врагам. Внутренняя башня и Ancient защищены скриптом `Shield`. Без вражеских миньонов рядом башня получает меньше урона (`Health.extraReduction`).
5. Потеря башен усиливает миньонов противника (`GameManager.MinionPower`).
6. Смерть `Ancient` вызывает `GameManager.EndMatch` → экран победы или поражения.

## Скрипты по папкам

### Assets/Scripts (игра)
| Скрипт | Что делает |
|---|---|
| `Team` | команда, тип объекта, цвета команд, кто кому враг |
| `Health` | здоровье, броня, щит, регенерация, события смерти и урона |
| `GameManager` | кредиты, счёт, бафф Pitmonster, пауза, магазин, конец матча, лента событий, подсказки |
| `GameSettings` | выбор героя, чувствительность и громкость (PlayerPrefs) |
| `PlayerController` | бег, прыжок, рывок с зарядами, поворот камеры мышью, отдача, толчок от платформы |
| `CameraCollision` | камера не проходит сквозь стены (SphereCast от героя к камере) |
| `PlayerShooting` | луч из центра экрана, разброс, отдача, магазин, перезарядка, хедшоты, трассер |
| `PlayerAbilities` | энергия и способность Q: урон всем врагам в радиусе |
| `UnitAI` | один ИИ на всех: миньоны идут по линии, боты ещё и отступают лечиться, нейтралы держатся у лагеря |
| `WaveSpawner` | волны миньонов, усиление от потерянных вражеских башен |
| `Tower` | башня: поиск цели (миньоны в приоритете), луч, правило «без миньонов меньше урона» |
| `Shield` | объект неуязвим, пока жив кто-то из `guardians` |
| `Ancient` | главный реактор: взрыв и конец матча |
| `Bounty` | награда за убийство, ластхит, счёт убийств, бафф Pitmonster, выпадающий предмет |
| `Respawner` | смерть и возрождение героя, время растёт с каждой смертью |
| `Interactable` | база для объектов «подойди и нажми E» |
| `ShopTerminal`, `HealingStation` | магазин и фонтан лечения (наследники `Interactable`) |
| `JumpPad` | прыжковая платформа: подбрасывает игрока через стену |
| `Pickup` | аптечка / энергия / кредиты, появляется снова через время |
| `ShopPanel` | магазин: категории, карточки, сборка, покупка в один клик |
| `UIManager` | HUD: полоски, способности, патроны, счёт, ближайшая башня, прицел, хитмаркер, виньетка урона |
| `WorldHealthBar` | полоска здоровья над головой (создаётся кодом) |
| `DamagePopup` | всплывающие цифры урона и «+15» кредитов |
| `MainMenu`, `SettingsPanel`, `MenuOrbit` | главное меню, настройки, облёт камеры вокруг героя |
| `TeamTint` | красит модель и иконку мини-карты в цвет команды |
| `MinionAnimation` | процедурные анимации миньонов поверх Idle/Walk: удар когтями, вздрагивание от попадания, падение при смерти (поворот костей в LateUpdate) |
| `GunAttach` | ставит винтовку в руки героя по позиции кистей (после анимации, в LateUpdate) |
| `BeamEffect`, `LightFade`, `Rotator` | визуальные эффекты: луч выстрела, гаснущая вспышка, вращение |
| `AutoTest` | инструмент разработчика: автопрогон билда со скриншотами (только с параметром `-autotest`) |

### Assets/Editor (сборка уровня)
| Скрипт | Что делает |
|---|---|
| `MidlineBuilder.cs` | настройка моделей Mixamo (Humanoid, Bake Into Pose), Animator Controller, материалы, процедурные текстуры, частицы, префабы юнитов |

| `MidlineBuilder.UI.cs` | HUD, пауза, магазин, экран конца, главное меню, Build Settings |

## Частые вопросы на защите
- **Как работает ластхит?** `Health.TakeDamage` сохраняет `LastAttacker`. `Bounty` при смерти проверяет, что это объект с тегом Player.
- **Почему магазин не ставит паузу?** `OpenShop` блокирует только ввод (`InputBlocked`), а `Time.timeScale` не трогает.
- **Как сделана стрельба?** `Camera.ViewportPointToRay` из центра экрана + случайный сдвиг (разброс), `Physics.Raycast`. Хедшот: попадание в верхние 0.35 м коллайдера.
- **Как работает мини-карта?** Вторая ортографическая камера сверху рендерит только слой Minimap в RenderTexture, его показывает RawImage. Иконки юнитов лежат на этом слое на высоте 60.
- **Как ходят миньоны?** NavMeshAgent по NavMesh, запечённому с объекта Environment. Точки линии `LaneL_1..5`, красные идут по ним в обратном порядке.
- **Как анимированы миньоны?** Ходьба и ожидание — клипы Mixamo через Animator (параметр Speed). Удар, вздрагивание и падение — скрипт `MinionAnimation`: в LateUpdate, после Animator, он поворачивает кости руки, корпуса и головы через `Animator.GetBoneTransform`.
- **Почему винтовка не прилипает к руке криво?** `GunAttach` каждый кадр направляет её от правой кисти к левой: обе руки держат оружие в анимации.
- **Зачем MidlineBuilder?** Вся расстановка карты и интерфейса описана кодом: поменял число, нажал «Собрать всё». Это и есть исходник карты.
