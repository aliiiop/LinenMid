# Midline: Neon City MOBA

Учебный проект на Unity 6 (6000.6.7f1, URP). MOBA с управлением от третьего лица:
ты сам бегаешь и стреляешь, а вокруг линии, волны миньонов, башни, магазин и Ancient.
Матч 2 на 2: ты и союзный бот против двух вражеских ботов.

**Авторы:** Жаксыбаев Алискер, Вагнер Альберт

## Управление
| Клавиша | Действие |
|---|---|
| WASD | бег |
| Мышь | прицел |
| ЛКМ | выстрел |
| R | перезарядка |
| Space | прыжок |
| Left Shift | рывок (заряды) |
| Q | энергетический взрыв (способность) |
| E | магазин / лечение у терминала |
| Esc | пауза |

## Правила
- Разрушь вражеский **Ancient** (красная база), пока враги не разрушили твой.
- Башни ломаются **по порядку**: внутренняя башня и Ancient под щитом, пока жива предыдущая защита.
- Без своих миньонов рядом башня получает на 70% меньше урона: веди волну.
- **Кредиты** дают только за добивание (последний выстрел). Магазин не ставит игру на паузу.
- Чем больше башен потеряла команда, тем сильнее миньоны противника.
- В джунглях: нейтралы (кредиты, аптечки) и **Pitmonster** (+25% урона команде на 90 с).
- Жёлтые прыжковые платформы перебрасывают через стены джунглей.
- Время возрождения растёт с каждой смертью.

## Как пункты ТЗ закрыты
| Пункт ТЗ | Где в игре |
|---|---|
| Условная карта | сцена `Game`: 2 линии, джунгли, 2 базы, город вокруг |
| Игровой персонаж, управление, камера | `PlayerController`, камера за плечом, `CameraCollision` |
| Здоровье | `Health` (у всех: игрок, боты, миньоны, башни) |
| Доп. механика | рывок с зарядами, способность Q, прыжковые платформы, магазин |
| 2 сцены | `MainMenu`, `Game` |
| Вид противника | миньоны, боты-герои, нейтралы, Pitmonster, башни |
| 2+ анимации | Rifle Idle / Rifle Run (герои), Idle / Zombie Walk (миньоны) |
| Игровой интерфейс | HUD: здоровье, энергия, способности, патроны, кредиты, счёт, мини-карта |
| Главное меню, пауза, победа/поражение | `MainMenu`, `PausePanel`, `EndPanel` со статистикой |
| Собираемый предмет | аптечки и энергоячейки (`Pickup`) |
| 2+ объекта взаимодействия | магазин (2 терминала), фонтан лечения, прыжковые платформы |
| Ссылки на ассеты | [ASSETS.md](ASSETS.md) |
| Исходники своих ассетов | `Sources/`, `Assets/Editor/MidlineBuilder*.cs` |
| Титры | главное меню → «Титры» |

## Как собрать проект
Сцены и префабы генерирует редакторский скрипт `Assets/Editor/MidlineBuilder*.cs`.
В Unity: меню **Midline → Собрать всё**, затем **Midline → Собрать билд Windows**
(билд появится в `Builds/Windows/Midline.exe`).

Объяснение всех скриптов: [CODE_GUIDE.md](CODE_GUIDE.md).
