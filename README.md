# Midline

Учебный проект на Unity. Командный шутер от третьего лица с механиками MOBA:
линии, волны миньонов, башни, герои, магазин, Ancient. Формат матча: 2 на 2.

## Управление
WASD — движение, мышь — прицел, ЛКМ — стрельба, R — перезарядка, Space — прыжок,
Left Shift — рывок, Q — способность, E — взаимодействие, Esc — пауза.

## Цель
Уничтожь внешние и внутренние башни и Ancient красной команды.
Ластхить миньонов за кредиты, покупай предметы на базе, убей Pitmonster для бафа.
